# Why this version has no front end

A localisation manager can inspect missing strings, give a translator a brief, record review evidence and prepare language files by talking to a coding agent. Read-only branded HTML shows the week's work and the release checklist.

A screen adds in-context previews, simultaneous editing, visual layout checks, mobile access and controlled sign-in. This free version does not supply those. PGlite permits one process at a time. Shared PostgreSQL is a database connection, not an authenticated team application. Enterprise DNA can build those workflows around your own version.

Plain text workflows work today without a network service. Rich document conversion, complex plurals, translation memory search and over-the-air delivery need additional scope. A human checks the final product before release. Nothing here deploys it.
